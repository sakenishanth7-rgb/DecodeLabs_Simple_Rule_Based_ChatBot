# 🤖 Simple Rule-Based ChatBot

## 📌 Overview

This project is a simple Rule-Based ChatBot developed using Python. The chatbot responds to predefined user messages using a dictionary-based approach and continues interacting with the user until an exit command is given.

The project demonstrates fundamental Python concepts such as dictionaries, loops, conditional statements, and user input handling.

---

## 🚀 Features

* Dictionary-based response system
* Predefined conversational messages
* Continuous interaction using an infinite loop
* Case-insensitive user input handling
* Exit functionality using "bye" or "exit"
* User-friendly chatbot responses

## ⚙️ How It Works

1. A dictionary stores predefined user messages and chatbot responses.
2. The chatbot continuously waits for user input.
3. User input is converted to lowercase for easier matching.
4. If the message exists in the dictionary, the corresponding response is displayed.
5. If the message is not recognized, the chatbot returns a default response.
6. The program ends when the user enters "bye" or "exit".
